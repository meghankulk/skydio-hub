Skydio UI Kit

The components, ontology, map types and principle linter behind the Skydio pages, packaged as one stylesheet and one script. Every specimen below is drawn at load by calling the kit with the props shown, so this page always matches the kit.

0 components12 principles, checked by SkydioUI.lint()Used by Skydio Live Ops and the Inventory

    Use it

    Load the two files, mount the icon sprite, and render inside an element with class sky. Components are pure functions: props in, an HTML string out.

    <link rel="stylesheet" href="kit/skydio-ui.css">
<script src="kit/skydio-ui.js"></script>

<div class="sky" id="screen"></div>
<script>
  const K = SkydioUI; K.mount();
  screen.innerHTML = K.PatrolCard({ mission, aircraft });
  const results = K.lint(screen, { surface: "desktop",
    focus: "X10-A", aircraft });
</script>

    Tokens

    Defined once on :root in skydio-ui.css. Swatches read the live CSS values.

    Data-attribute contract

    The attributes components emit. The linter and live apps read these, so a new component is checked by the same rules as soon as it emits them.
